| 项 | 内容 |
|---|---|

| 平台 | Android 为主（arm64 发布包），Windows 桌面同步支持 |

## 1. 产品概述

### 1.1 定位

本地优先的**事件日历管理** App：把散落在手动录入、AI 文本、QQ 邮箱、截图、语音里的日程（面试、笔试、就诊、约会等**任何带时间的事**）统一抽取为事件，经用户确认后写入日历，本地持久化，支持导出备份与 ICS 分享。

### 1.2 核心闭环

```
多渠道输入 → AI 识别/抽取 → 人工确认（可改） → 加入日历 → 完成跟踪/红点提醒 → 导出备份
```

### 1.3 目标用户与原则

- 目标用户：求职者为主，但不限定面试 —— 事件是通用的（就诊、约会、笔试等都被正确对待）。
- 设计原则：
  1. **不依赖第三方日历**：自建 UI、自存数据（安卓 ical4j 对 ICS 解析过于严格的教训）。
  2. **AI 只做候选，确认才落库**：识别结果一律进确认清单，可查看原文、可修改后再加入。
  3. **本地优先**：数据、配置全部存本机；存储不可用时界面必须有常驻警告，不静默失败。
  4. **文案不写死场景**：不出现「只能面试用」类限制（如完成提示为「事件开始后才能标记完成」）。

## 2. 功能需求

### 2.1 日历与事件（P0）

**月历视图（首页）**
- 月历格子：日期数字、**红点徽标**（事件数，已完成事件不计入红点）、今天高亮、选中态、月份左右切换。
- 选中日期下方展示当日事件列表；点击事件进详情。
- 顶部导航：AI 助手、今天、邮箱导入、数据与备份（图标入口）。
- 右下角 **+ 按钮** → 弹出添加方式：「手动添加」/「截图识别」。

**事件字段**

| 字段 | 必填 | 说明 |
|---|---|---|
| 标题 | ✅ | |
| 公司 / 岗位 / 轮次 | ❌ | 轮次：一面/二面/三面/终面/HR面/笔试/测评 |
| 开始时间 | ✅ | |
| 结束时间 | ❌ | 默认 = 开始 + 时长 |
| 地点 | ❌ | 详情页**可长按选中复制、可一键复制** |
| 会议链接 | ❌ | 详情页可点击打开 |
| 颜色标记 | ❌ | 粉/紫/蓝/绿/橙/红 |
| 备注 | ❌ | |
| 完成时间 | 系统 | 见下 |

**完成规则**：事件**开始前不允许标记完成**，拦截提示「事件开始后才能标记完成」（防「哪些事还没做」失真）。

**其他**：事件详情页（含编辑、删除、ICS 分享）、时间冲突检测（写入前提示与既有事件冲突）。

### 2.2 录入渠道

#### a) 手动添加（P0）
表单填写，见上表。

#### b) AI 助手 — 文本抽取（P0）
- 入口：首页「AI 助手」。
- 粘贴任意文本（邮件/通知/聊天记录）→「智能提取」→ 结果卡（类别、置信度、字段）→ 确认写入。
- **语音输入**：输入框麦克风按钮，调**本机系统语音识别**（`speech_to_text`，中文 zh_CN）：
  - 点击开始听写，识别文字先进入「正在听」小窗，停顿 3 秒自动结束（最长 60 秒），
  - 结束后一次性写入输入框（避免逐帧改输入框把页面顶出屏幕）；
  - 权限未批/服务不可用时按钮**始终可点**，点击自动重试初始化并给出指引，不做死按钮。
- 时间冲突提示卡。

#### c) QQ 邮箱导入（P0）
- 配置：**专属配置管理页**（多份邮箱账号、点选「使用中」、新增/编辑/删除），结构与 AI 配置页一致；同步页只展示当前账号与状态徽标。
- 同步流程：拉取（IMAP）→ 过滤已处理 → **每批 8 封**送 AI 通读 → 候选清单 → 确认/修改/忽略 → 批量写入。
- **增量游标**：只拉上次游标之后的邮件；游标仅在候选全部处理完后推进；手动选时间段的回扫不推游标。
- **已处理去重**（`ProcessedMailStore`）：已确认/忽略的邮件不再重复出现。
- **查重**：日历已有「同公司 + 开始时间 ±5 分钟」的事件 → 弹窗「覆盖 / 跳过 / 取消全部」。
- **范围选择**：可选手动起止日期回扫，不选则自动增量。
- 候选卡点开进编辑器（**原文可读 + 字段可改**）。

#### d) 截图识别任务（P0）
- 入口：首页 **+ → 截图识别**。
- 多选截图（相册，最多 **9 张**），可逐张删除、继续添加；安卓端压缩（最长边 1568、质量 85），单图 >12MB 拒收并提示。
- AI **识别图中文字 + 总结任务**（面试/笔试/材料准备等逐条拆出），返回识别全文与任务清单。
- **每批 3 张并发**识别（思考模型单张几十秒，并发压总耗时），进度实时显示。
- 任务确认清单：勾选、点开编辑（看该图识别原文 + 改字段）、忽略、加入日历；查重逻辑与邮箱一致（提示语为「新识别的信息」）。
- 任务无时间时拦截，提示先点开设置时间。

#### e) 解析会话与暂停（P0，可靠性）
- 邮件/截图解析跑在**单例会话**（`MailParseSession` / `ScreenshotParseSession`）中，**退出界面不中断**，重新进入挂载监听即可继续看进度与结果。
- 解析中提供**暂停 / 继续 / 停止**：暂停在当前批次完成后生效，已识别结果全部保留。
- 边界：进程被系统杀掉时 —— 邮件因游标未推进会下次重新识别（不丢）；截图需重新选图。

### 2.3 AI 配置（P0）

- **多份 AI 档案**（OpenAI 兼容 chat completions），点选切换、测试连接、编辑、删除。
- 默认：`https://api.xiaomimimo.com` + 模型 **`mimo-v2.6-pro`**（已实测调通）；预设含 DeepSeek、OpenAI；模型快捷芯片含 `mimo-v2.6-pro/flash/pro-ultraspeed`、`mimo-v2.5*` 等。
- **思考模式**（推理模型先「想」再答）：**默认开启**，更准（尤其相对时间推算），慢（每封约 35s vs 2-6s）；编辑页可关，选择记住。旧数据自动迁移到新默认。
- token 预算随思考自动加大（思考 8000/16000，关闭 4000/8000），防止 content 被思考占空。
- 失败信息翻译成人话（401/403/404/429/400、超时、DNS、CORS 等，附请求地址与响应片段）。

**抽取 schema（三处共用同一套结构）**：

```json
{
  "is_interview": true,
  "category": "interview_invite|reschedule|cancel|assessment|rejection|offer|other",
  "confidence": 0.0,
  "company": "", "role": "", "round": "",
  "interview_start": "ISO 8601", "duration_minutes": 60,
  "time_is_explicit": false,
  "location": "", "meeting_url": "", "contact": "",
  "notes": "", "summary": ""
}
```
- 批量：输出等长 JSON 数组，与输入一一对应；宽容解析（去 markdown 包裹、截取 `{}`/`[]`）。
- 截图：`{recognized_text, tasks:[...]}`，任务项 `due_time` 对应开始时间。
- 规则要点：只有「邀请参加面试」算面试；相对时间基于给定「当前时间」换算且 `time_is_explicit=false`。

### 2.4 配置持久化（P0）

| 配置 | 存储 | 说明 |
|---|---|---|
| AI 档案（含 key、思考开关） | SharedPreferences | 多份 + 使用中 |
| QQ 邮箱（邮箱 + 授权码） | SharedPreferences（兼容迁移旧的 flutter_secure_storage 数据） | 历史「部分手机重启后读不到加密存储」问题改为与 API Key 同存储 |
| 同步游标 / 已处理邮件 | 本地 | 见 2.2c |
| 界面风格 | SharedPreferences（key `app_style`） | 见 2.6 |

- 所有配置页有**「已配置 / 未配置」「✓ 可用」常驻徽标**；存储写入失败有红色常驻警告。

### 2.5 数据与备份（P1）

- 持久化状态卡：「数据已持久化保存 / 仅内存」+ 记录条数；**存储位置默认收起，点「查看」平滑展开**（路径可选中复制）。
- 导出：全部事件 JSON → 系统剪贴板；导入：粘贴恢复，**追加不覆盖**。
- ICS 分享：RFC 5545（UID `event-{id}@interview-calendar.local`，时间 UTC），经系统分享发送。

### 2.6 双风格主题（P1）

| 风格 | 特征 | 状态 |
|---|---|---|
| **经典卡通**（默认） | 冷灰蓝背景、软阴影、无描边、彩色点缀（原版视觉） | 默认 |
| **描边风格（Lowpoly）** | 米白纸底、全卡 2px 黑描边、纯黑硬阴影、黑网格日历、小圆角（贴纸/低多边形质感） | 可选 |

- 切换入口：AI 助手 → ⚙ 设置 → 顶部「界面风格」卡；**即时生效、选择持久化**，切换不影响数据与任务。
- 实现约定：会随风格变化的取值一律走 `AppTheme` 动态 getter（`outline`/`hardShadow`/圆角等），经典模式描边色=全透明自动隐身；这些取值**禁止出现在 const 上下文**。

### 2.7 中文化（P0）

- 全中文界面；`flutter_localizations` 固定 `zh_CN` —— 日期/时间选择器、Material 组件全部中文（修复过英文 OK/Cancel 问题）。

## 3. 非功能需求

### 3.1 性能与超时

| 场景 | 超时 | 备注 |
|---|---|---|
| AI 连接测试 | 30s（思考开 60s） | |
| 单封抽取 | 90s | |
| 批量抽取（8 封/批） | 180s | |
| 截图识别（单请求） | 150s | 每批 3 张并发 |
| 思考模式实测 | 小图 ~7s；真实截图 17-19s（思考占 6-7 成） | 可关思考或换 `flash/ultraspeed` 提速 |

### 3.2 安全

- 邮箱授权码、API Key 均存本机 SharedPreferences（与用户要求「与 API Key 一致地保存」对齐）；不上传任何第三方服务器，网络只发往用户配置的 API 地址与 QQ 邮箱服务器。
- **风险项**：代码内置了一枚明文 MiMo 预设 key（个人自用）——**分享仓库/安装包前必须移除**。
- 权限：INTERNET、RECORD_AUDIO（语音）；Android 11+ 声明 `RecognitionService` 可见性、URL VIEW queries。

### 3.3 兼容性

| 项 | 值 |
|---|---|
| minSdk / targetSdk | 24（Android 7.0+）/ 36 |
| 发布包 | **仅 arm64**（`--target-platform android-arm64`，过滤残留 ABI 目录） |
| 包体积 | ≈23.6MB |
| 签名 | v2 + v3（minSdk 24 下无 v1，正常）；发布 keystore 已配，可覆盖安装升级 |
| 平台差异 | 语音识别依赖系统识别服务；截图选择双平台可用；桌面端数据用 JSON 文件（database_io） |

### 3.4 可靠性

- AI/存储的失败都必须**界面可见**（错误卡片 / 红色常驻警告），不静默。
- 重复导入防护三层：游标、已处理标记、落库前查重弹窗。

## 4. 技术架构概要

```
lib/
├─ main.dart                 双风格监听 + zh_CN 本地化 + 风格恢复
├─ models/                   event / llm_profile / mail_message
├─ services/
│   ├─ database*.dart        SQLite(Android) / JSON(桌面) / web(localStorage)，schema v2
│   ├─ llm_service.dart      OpenAI 兼容调用：单条/批量/截图（视觉）抽取 + 错误翻译
│   ├─ mail_service*.dart    IMAP（enough_mail），条件导入
│   ├─ mail_parse_session    邮件解析会话（单例，暂停/继续/停止）
│   ├─ screenshot_parse_session  截图解析会话（单例，批量并发）
│   ├─ profile_store / mail_config_store / mail_cursor_store / processed_mail_store
│   ├─ event_dedup           查重 + 覆盖确认弹窗（邮箱/截图共用）
│   ├─ extraction_to_event   抽取结果 → 事件（AI 助手/邮箱/截图共用）
│   ├─ conflict_detector     时间冲突
│   └─ ics_export / ics_share
├─ screens/                  首页、AI 助手、邮箱导入、截图识别、配置管理、编辑器、详情、表单、数据备份、设置
├─ widgets/                  月历、日期格、事件卡
└─ theme/app_theme.dart      双风格主题（动态取值约定见 2.6）
```

主要依赖：`sqflite`、`enough_mail`、`image_picker`、`speech_to_text`、`flutter_secure_storage`（仅历史迁移）、`share_plus`、`url_launcher`、`shared_preferences`、`flutter_localizations`、`http`。

## 5. 构建与发布

```bash
flutter pub get
flutter analyze          # 应只剩历史遗留 2 项（模板测试错误 + 1 条 const 提示）
flutter build apk --release --target-platform android-arm64
# 产物：build/app/outputs/flutter-apk/app-release.apk
```

环境要点（本机）：JAVA_HOME → Android Studio jbr；镜像 `FLUTTER_STORAGE_BASE_URL` / `PUB_HOSTED_URL`（flutter-io.cn）；Gradle 堆 1.5G（内存紧张曾 OOM）；SDK 的 `flutter.bat` 已打补丁（引导重试被 `2>NUL` 吞错导致挂起，备份 `flutter.bat.bak`，升级 SDK 后需重打）。

发布前验收（冒烟）：安装/覆盖、双风格切换并记住、手动+AI+邮件+截图+语音五条录入链路、暂停/退出继续、查重弹窗、完成拦截、备份导出导入、日期选择器中文。

## 6. 已知限制与后续候选

**已知限制**
1. 思考模式默认开导致邮件/截图识别偏慢（可关或换 flash/ultraspeed 模型）。
2. 仅邮件文本走 IMAP（QQ 邮箱验证）；未做通用邮箱向导。
3. 发布包仅 arm64；无 v1 签名（符合 minSdk 24）。
4. 代码内置明文预设 API key，分享前须清理。
5. 模板测试 `test/widget_test.dart` 报历史错误（不影响 App 构建）。
6. 截图识别进程被杀后需重新选图（邮件不会丢，见 2.2c）。

**后续候选（未承诺）**：定时提醒（通知）、通用 IMAP/多邮箱向导、截图压缩调优与失败重试、事件重复规则（每周/每月）、多语言、桌面发布包签名与分发。
